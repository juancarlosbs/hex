# Hex

Native API client for **REST and SOAP/WSDL**, built for devs who suffer with legacy tooling.

SoapUI is a 2005 Java monster. Postman/Insomnia treat SOAP as a second-class citizen.
Hex fills a SOAP operation from a **schema-generated form** — no hand-edited XML envelopes —
while staying just as capable for REST, in a fast, native, git-friendly desktop app.

## The hero flow

```
empty state → "Import WSDL" → operations appear in sidebar
→ click an operation → pre-built form (required fields marked, enums in dropdown)
→ fill in → Send → timing waterfall + response tree with copy-leaf
```

## Differentiators

1. **Schema-generated form** — fill a SOAP operation without writing XML.
2. **Isolated copy-leaf** — copy a response value without its key/tag.
3. **Real timing waterfall** — DNS/TCP/TLS/TTFB/download per request.
4. **Git-friendly storage** — one file per request, native speed.

## Stack

Tauri v2 + React 19 (TypeScript) + Rust engine. Desktop, dark-first, local-first.

- **Rust**: tokio, hyper (instrumented HTTP engine), hickory-resolver (DNS), tokio-rustls (TLS), roxmltree/quick-xml (WSDL/XSD/envelope), serde, thiserror/anyhow.
- **Bridge**: `tauri-specta` (generates `src/bindings.ts`, typed).
- **Frontend**: React 19 + Vite + TS, Tailwind + shadcn/ui, zustand, @tanstack/react-query + react-virtual, react-resizable-panels, @uiw/react-codemirror.

## Getting started

```bash
pnpm install
pnpm tauri dev
```

## Install (macOS)

Hex isn't notarized (no paid Apple Developer account yet), so a direct download
gets Gatekeeper-quarantined. Install with the script instead — it grabs the
latest release for your architecture and clears the quarantine flag:

```bash
curl -fsSL https://raw.githubusercontent.com/juancarlosbs/hex/main/scripts/install.sh | bash
```

|---|---|
| `pnpm tauri dev` | Run the app in development |
| `pnpm tauri build` | Build the app |
| `pnpm test` | Frontend tests (Vitest) |

| `pnpm test:e2e` | End-to-end tests |

| `pnpm release <patch\|minor\|major>` | Cut a release (from `main`) |

## Project structure

```
src-tauri/src/
  domain/        # pure domain: request, schema (SchemaNode), envelope, response
  engine/        # instrumented HTTP engine + connector + envelope serializer
  wsdl/          # pipeline: parse -> resolve(imports) -> xsd -> SchemaNode
  persistence/   # collections/environments/history (serde + fs)
  commands/      # thin #[tauri::command] handlers
src/
  bindings.ts    # generated by tauri-specta — do not edit
  store/  features/  components/  lib/api.ts  App.css (design tokens)
docs/            # architecture, domain model, SOAP engine, UI, testing, ADRs
```
